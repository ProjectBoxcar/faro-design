# Status reports

Daily handoffs for leadership live here.

| File | Purpose |
|------|---------|
| [TEMPLATE.md](./TEMPLATE.md) | Structure and rules for every report |
| `YYYY-MM-DD.md` | One report per day (first: [2026-07-28.md](./2026-07-28.md)) |

**How to write the next one**

1. Copy `TEMPLATE.md` → `YYYY-MM-DD.md` (or copy yesterday’s file).
2. Leave **Product context**, **Stack**, and most of **Achievements to date** unless something durable changed.
3. Rewrite only **Today** (and **Header** / **Notes** if needed).
4. Keep **Today** as a short, concrete **Done:** list.
