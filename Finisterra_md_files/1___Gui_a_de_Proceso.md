**1.**⤴️**Guía de Proceso**



**Guía de Proceso**

Quién resuelve cada apartado y cómo se aborda con el cliente.



**Resumen**

| **Pilar**    | **El cliente**               | **El diseñador**                              |
| ------------ | ---------------------------- | --------------------------------------------- |
| Realidad     | Habla, cuenta, describe      | Pregunta, estructura, sintetiza               |
| Identidad    | Se abre, reflexiona, declara | Interpreta, articula, formaliza               |
| Imagen       | Facilita contactos           | Diseña encuesta, analiza, contrasta, concluye |
| Comunicación | Valida y aprueba             | Propone, define, redacta                      |
| Planeación   | Aprueba en momentos clave    | Propone, escribe, evalúa                      |
| Diseño       | Elige y aprueba con guía     | Explora, nombra, diseña, argumenta, aplica    |

El documento estratégico es 100% trabajo del diseñador, presentado al cliente para validación.



**Realidad: el cliente habla, el diseñador pregunta.**

| **Apartado**                | **Quién lo resuelve**  | **Cómo**                                                     |
| --------------------------- | ---------------------- | ------------------------------------------------------------ |
| Problema                    | El cliente             | Él sabe qué dolor tienen sus clientes                        |
| Solución                    | El cliente             | Él sabe qué ofrece                                           |
| Propuesta de valor          | Colaborativo           | El cliente da la materia prima, el diseñador lo sintetiza en una frase |
| Diferencial                 | Colaborativo           | El cliente sabe qué hace distinto, el diseñador lo articula  |
| Cliente ideal               | El cliente             | Él sabe con quién trabaja mejor                              |
| Momento del negocio         | El cliente             | Él sabe en qué etapa está                                    |
| Contexto de mercado         | Colaborativo           | El cliente conoce su mercado, el diseñador investiga y estructura |
| Particularidades operativas | El cliente             | Solo él sabe sus reglas no escritas                          |
| Arquitectura de marca       | Colaborativo           | El cliente sabe qué marcas tiene, el diseñador diagnostica la relación |
| Servicio y estructura       | El cliente             | Es su negocio                                                |
| Canales y capacidad         | El cliente             | Es su operación                                              |
| Criterios de evaluación     | El diseñador (interno) | El cliente nunca ve esto                                     |

**Identidad: el cliente se abre, el diseñador interpreta.**

| **Apartado**                   | **Quién lo resuelve** | **Cómo**                                                     |
| ------------------------------ | --------------------- | ------------------------------------------------------------ |
| Origen                         | El cliente            | Es su historia, solo él la puede contar                      |
| Autopercepción                 | El cliente            | Solo él sabe cómo se ve                                      |
| Aspiración                     | El cliente            | Solo él sabe hacia dónde quiere ir                           |
| Principio                      | Colaborativo          | El cliente dice qué no sacrificaría, el diseñador lo formaliza |
| Creencias                      | El cliente            | Son sus convicciones                                         |
| Posición frente a la industria | Colaborativo          | El cliente da la perspectiva, el diseñador la estructura y articula |
| Golden Circle                  | Colaborativo          | El cliente da las respuestas crudas, el diseñador las destila |

**Imagen: el diseñador trabaja, el cliente solo facilita contactos.**

| **Apartado**              | **Quién lo resuelve** | **Cómo**                                                     |
| ------------------------- | --------------------- | ------------------------------------------------------------ |
| Diseño de la encuesta     | El diseñador          | Las preguntas nacen de la identidad ya definida              |
| Selección de respondentes | Colaborativo          | El cliente propone contactos, el diseñador guía la selección |
| Envío de la encuesta      | El cliente            | Él tiene la relación con los respondentes                    |
| Análisis de patrones      | El diseñador          | El cliente no analiza su propia percepción                   |
| Contraste con identidad   | El diseñador          | Es el ejercicio técnico central del pilar                    |
| Hallazgos y brecha        | El diseñador          | Se presenta al cliente como conclusión, no como proceso      |

**Comunicación: el diseñador crea, el cliente valida.**

| **Apartado**          | **Quién lo resuelve**                    | **Cómo**                                                     |
| --------------------- | ---------------------------------------- | ------------------------------------------------------------ |
| Propósito             | El diseñador propone, el cliente valida  | Nace de todo lo anterior, el cliente no lo escribe           |
| Valores               | El diseñador propone, el cliente valida  | Ordenados por la encuesta, articulados por el diseñador      |
| Personalidad          | El diseñador define, el cliente confirma | Se define desde patrones de comportamiento observados        |
| Tono de voz           | El diseñador define, el cliente confirma | El cliente no sabe describir su tono, lo vive                |
| Promesa de marca      | El diseñador propone, el cliente valida  | Es síntesis de todo, requiere oficio de redacción            |
| Arquitectura de marca | El diseñador define, el cliente valida   | Define cómo se relacionan las marcas entre sí. El inventario de qué existe viene de Realidad |

**Aprobación estratégica**

| **Apartado**          | **Quién lo resuelve**                   | **Cómo**                                                     |
| --------------------- | --------------------------------------- | ------------------------------------------------------------ |
| Documento estratégico | El diseñador escribe, el cliente valida | Se presenta al cliente para revisión. Si hay ajustes, se iteran antes de pasar a planeación |

**Brief Estratégico: 100% trabajo del diseñador.**

| **Apartado**                     | **Quién lo resuelve** | **Cómo**                                                     |
| -------------------------------- | --------------------- | ------------------------------------------------------------ |
| Patrón central                   | El diseñador          | Extrae las ideas que se repiten en los 4 pilares sin haber sido forzadas |
| Tensión principal                | El diseñador          | Identifica la brecha más importante entre identidad e imagen |
| Restricción                      | El diseñador          | Define qué límites impone el principio institucional al diseño |
| Territorio emocional             | El diseñador          | Sintetiza el espacio expresivo donde la marca debería vivir  |
| Lo que el concepto debe resolver | El diseñador          | Formula la pregunta que el concepto de marca responde        |

**Planeación: el diseñador propone, el cliente aprueba.**

| **Apartado**           | **Quién lo resuelve**                   | **Cómo**                                                     |
| ---------------------- | --------------------------------------- | ------------------------------------------------------------ |
| Concepto de marca      | El diseñador propone, el cliente valida | Nace de la estrategia aprobada. El cliente no lo escribe pero debe entenderlo y aprobarlo |
| Insights reutilizables | El diseñador                            | Se documentan durante la destilación del concepto. Solo se reutilizan los que pasan el filtro del concepto |
| Manifiesto             | El diseñador escribe, el cliente valida | El cliente debe sentirse representado al leerlo. Si no se reconoce, se itera |
| Auditoría de marca     | El diseñador                            | Evaluación técnica contra la estrategia. El cliente aporta los activos existentes |
| Plan de diseño         | Colaborativo                            | El diseñador propone el alcance, el cliente aprueba porque define presupuesto y tiempos |

**Diseño: el diseñador ejecuta, el cliente aprueba en momentos clave.**

**Naming**

| **Apartado**          | **Quién lo resuelve**                   | **Cómo**                                                     |
| --------------------- | --------------------------------------- | ------------------------------------------------------------ |
| Restricciones         | Colaborativo                            | El diseñador define las restricciones desde la estrategia. El cliente confirma que reflejan su realidad |
| Perfil fonético       | Colaborativo                            | El diseñador pregunta por don'ts, musts y referencias personales. El cliente aporta sus gustos fonéticos, idiomas de preferencia, y lo que no quiere que suene |
| Exploración           | El diseñador                            | Abre direcciones, prueba candidatos, descarta con argumentos. El cliente no participa en cada descarte |
| Evaluación            | El diseñador                            | Prueba de filtro, evaluación contra el brief, prueba de reconocimiento, prueba fonética bilingüe, connotaciones reales |
| Verificación técnica  | El diseñador                            | Dominio, redes sociales, registro legal, homónimos en el mismo sector. Se verifica antes de presentar al cliente |
| Presentación          | El diseñador presenta, el cliente elige | Se presentan 2-3 candidatos evaluados con argumento. El cliente elige con guía, no al azar |
| Aseguramiento digital | Colaborativo                            | Se compra el dominio y se crean los handles inmediatamente después de la elección. No se espera |

**Territorios visuales y definición**

| **Apartado** | **Quién lo resuelve** | **Cómo**                                                     |
| ------------ | --------------------- | ------------------------------------------------------------ |
| Exploración  | El diseñador          | Construye 2-3 territorios con referencias curadas. Cada uno argumentado contra concepto, nombre, personalidad y brecha |
| Definición   | Colaborativo          | El diseñador presenta territorios y argumenta. El cliente elige con guía. Se documenta qué se elige, qué se sacrifica, qué se gana |

**Sistema de marca**

| **Apartado**                 | **Quién lo resuelve**                   | **Cómo**                                                     |
| ---------------------------- | --------------------------------------- | ------------------------------------------------------------ |
| Logo: exploración            | El diseñador                            | Mínimo 3 direcciones argumentadas                            |
| Logo: evaluación             | El diseñador                            | Dos niveles: estratégico (concepto, nombre, personalidad, territorio) y técnico (estilo, clasificación tipológica, compatibilidad semántica, legibilidad, calidad gráfica, singularidad, versatilidad, vigencia, reproducibilidad, pregnancia) |
| Logo: definición             | Colaborativo                            | El diseñador argumenta la dirección. El cliente valida       |
| Sistema de color             | El diseñador propone, el cliente valida | Paleta con argumento, no solo preferencia. Cada color tiene una razón |
| Sistema tipográfico          | El diseñador                            | Familias con roles claros. Se define por pertinencia, no por tendencia |
| Elementos del sistema visual | El diseñador                            | Patrones, contenedores, texturas, divisores. Nacen del logo o del principio generativo del sistema |
| Dirección fotográfica        | El diseñador propone, el cliente valida | Define el estilo de imagen coherente con el territorio       |

**Cierre**

| **Apartado**    | **Quién lo resuelve** | **Cómo**                                                     |
| --------------- | --------------------- | ------------------------------------------------------------ |
| Aprobación      | Colaborativo          | Presentación formal del sistema completo. El cliente valida contra concepto de marca y plan de diseño |
| Aplicación      | El diseñador          | Pruebas funcionales en soportes reales. El cliente recibe el resultado final |
| Manual de marca | El diseñador          | Documenta el sistema completo con lineamientos de uso. El cliente lo usa como guía de implementación |
